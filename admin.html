⚙ Auto-Publish Setup (GitHub Pages)

Ye ek baar set up karne ke baad, har naya post / edit / delete automatically aapki live website par publish ho jayega — koi manual download-upload nahi karna padega. Ye sirf tab kaam karta hai jab aapki site GitHub Pages par hosted ho.
Kaise set up karein:
1. GitHub.com par account banayein (free), ek naya public repository banayein aur usmein index.html, admin.html, product.html upload karein.
2. Repo Settings → Pages mein jaakar GitHub Pages enable karein — apki site ka URL mil jayega.
3. GitHub.com → Settings → Developer Settings → Fine-grained personal access tokens → New token banayein. Repository access mein sirf apna wahi repo select karein, aur Permissions mein "Contents: Read and write" dein.
4. Neeche wo details bharein aur "Connection Test Karein" dabayen.
